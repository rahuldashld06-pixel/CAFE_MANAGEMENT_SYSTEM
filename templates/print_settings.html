Send the kitchen ticket and the bill to the printer on their own.

sec
Enter 0 to print immediately. A few seconds leaves room to cancel a mistaken order before the kitchen starts it.
Browsers always show their print dialog before sending a page to the printer. To have these print silently, start the browser with kiosk printing on — for Chrome or Edge, launch it with --kiosk-printing and set the till's receipt printer as the default. Without that, each print still opens the dialog and someone has to press Print.
